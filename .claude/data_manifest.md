# Data File Manifest

When working with match data, **always read `unified_report.json` first**. It contains all available intelligence for each match in one file.

## Quick Reference

| Question | Read This File |
|----------|---------------|
| Full match intelligence (predictions, odds, players, form, weather, lineups, etc.) | `data/upcoming/unified_report.json` |
| Just the ensemble predictions | `data/upcoming/predictions_unified.json` |
| Recommended bets with stakes | `data/upcoming/unified_bet_slip.json` |
| Current league standings | `data/upcoming/standings.json` |
| Historical features (all seasons) | `data/features/features.parquet` |
| Model metadata | `data/models/universal/catboost_no_odds_metadata.json` |
| Deployment state / model version | `data/models/deployment_state.json` |
| Ensemble weights + optimization results | `data/optimization/ensemble_optimization.json` |
| Betting history + results | `data/betting/history.json` |
| Bankroll state | `data/betting/bankroll.json` |

## unified_report.json (THE PRIMARY FILE)

Generated by `scripts/prediction/generate_unified_report.py` as Step 32 of the pipeline.

**Important**: This file contains BOTH upcoming and completed matches with different schemas. Check `_sections_available` to see what data is present for each match.

**Upcoming matches** (have predictions — use for betting decisions):
```
{
  "match": "Atalanta vs Cremonese",
  "date": "2026-02-09",
  "time": "18:00",
  "venue": "Gewiss Stadium",
  "prediction": { outcome, probabilities {home, draw, away}, confidence, methods_used },
  "value_analysis": { has_value, best_bet, edge },
  "draw_analysis": { draw_score, is_draw_candidate, indicators },
  "bets": [{ market, selection, odds, bookmaker, edge_pct, stake, confidence }],
  "goals": { expected_home, expected_away, expected_total, over_2_5_prob, btts_yes_prob },
  ... (up to 20+ sections when data is available)
}
```

**Completed matches** (no prediction — have historical data only):
```
{
  "match": "Bologna vs Udinese",
  "bets": [...],
  "goals": { expected_home, expected_away, expected_total },
  "odds": { bookmaker data },
  "players": { key players },
  "form": { home_form, away_form },
  ... (typically 15-20 sections, but NO prediction/date/time/venue)
}
```

All possible sections per match:
- `prediction`, `value_analysis`, `draw_analysis` — upcoming only
- `date`, `time`, `venue` — upcoming only
- `bets`, `goals`, `players`, `form`, `h2h`, `weather`, `referee`
- `lineups`, `market_intelligence`, `cross_market_signals`, `bookmaker_analysis`
- `odds`, `extended_markets`, `margin_prediction`, `sentiment`
- `btts`, `cards`, `corners`, `standings`
- `_data_sources` (count), `_sections_available` (list)

## Data Flow

```
Scrapers → data/parsed/*.parquet + data/external/*.parquet
         ↓
features/build.py → data/features/features.parquet (863 columns)
         ↓
predict_unified.py → data/upcoming/predictions_unified.json
         ↓
betting_unified.py → data/upcoming/unified_bet_slip.json
         ↓
generate_unified_report.py → data/upcoming/unified_report.json (ONE FILE FOR EVERYTHING)
```
